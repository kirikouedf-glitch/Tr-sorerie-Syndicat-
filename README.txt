Trésorerie Syndicat PWA

IMPORTANT : pour être installable comme application, cette PWA doit être ouverte depuis une adresse HTTPS (ou localhost). Ouvrir directement index.html depuis le gestionnaire de fichiers ne suffit pas.

Fichiers à publier tels quels sur un hébergement HTTPS : index.html, manifest.webmanifest, sw.js, icon.svg.

Après publication :
1. ouvrir l'adresse dans Chrome sur Android ;
2. menu ⋮ ;
3. choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».

La V1 conserve les données localement dans le navigateur. Utiliser régulièrement Réglages > Télécharger une sauvegarde.
